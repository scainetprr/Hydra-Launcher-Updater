CARACTERÍSTICAS

⚡

Versiones Múltiples

Soporte completo para Vanilla, Fabric y Forge. Instalación 1-click, snapshots, releases y versiones antiguas con reutilización inteligente.

Modpacks

Sistema de modpacks con escaneo recursivo de subcarpetas. Crear, editar, eliminar y aplicar con un clic. Guardado persistente.

Autenticación Dual

Microsoft OAuth2 con refresh automático y cuentas offline con UUID v3 determinístico. Compatible con servidores online-mode=false.

Detección automática de Java y RAM, JVM args optimizados con G1GC, string deduplication y flags de rendimiento avanzados.

Auto-Actualizador

Actualizaciones automáticas desde GitHub Releases. Descarga silenciosa, verificación SHA512 e instalación al cerrar.

— PREGUNTAS FRECUENTES —

FAQ

¿Es seguro usar Hydra Launcher?

+

Sí. No recopilamos datos personales, no hay telemetría oculta y el código es auditable. Los tokens de Microsoft se guardan localmente cifrados y solo se usan para autenticación.

¿Puedo usar mi cuenta Microsoft premium?

+

Sí. Usamos el flujo OAuth2 oficial con refresh token automático. Tu sesión se renueva sola y nunca guardamos tu contraseña.

¿Dónde se guardan mis mods y configuraciones?

+

En tu carpeta nativa %APPDATA%\.minecraft. Mods en mods/, configuración en hydra-config.json, cuentas en hydra-accounts.json. No creamos carpetas separadas.

¿Cómo actualizo el launcher?

+

El auto-updater verifica actualizaciones al iniciar, descarga en segundo plano y la instala al cerrar. También puedes forzar la comprobación desde Ajustes → Actualizaciones.

Intel HD 4600 crashea (ig75icd64.dll), ¿qué hago?

+

Es un problema conocido de drivers Intel, no del launcher. Prueba: actualizar drivers de Intel, usar --enable-native-access=ALL-UNNAMED en JVM args, o asignar más RAM. El launcher ya incluye este flag.

¿Puedo redistribuir el instalador en mi web?

+

No. Hydra Launcher es propiedad intelectual de Hydra Studio. Queda prohibida su redistribución, modificación e ingeniería inversa. Consulta los Términos y Condiciones.

¿Cómo reporto un bug?

+

Únete a nuestro Discord o abre un issue en GitHub. Incluye logs, versión del launcher y pasos para reproducir.
